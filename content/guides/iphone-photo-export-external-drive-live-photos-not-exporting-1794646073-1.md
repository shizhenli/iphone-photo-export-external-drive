You copied your iPhone photo library to an external drive, but the still images are there while each Live Photo's paired video is missing.  

## Confirm what actually copied
Open the export folder on the external drive and inspect a few Live Photo stills. On a Mac, select a still and press Command+I; on Windows, right-click and choose Properties. A complete Live Photo export usually includes both a HEIC/JPG still and a short MOV file with the same base name. If you see only the still, note the exact filename and check whether any MOV files exist at all. If MOVs are present but renamed, the pairing metadata may be broken rather than the video lost.

## Check the source and the copy method
On the iPhone, open Photos, select a Live Photo, and swipe up to confirm it shows Live. Then review how you exported: Finder or Image Capture on Mac, File Explorer on Windows, or a cloud sync folder. If you used a drag-and-drop that only selected stills, the videos were never included. Re-export a small test set of five Live Photos using the same method and inspect the results before touching the full library.

## Verification test
Create a new folder on the external drive. Export five known Live Photos into it. Confirm each has a matching MOV and that the still opens. Then disconnect and reconnect the drive and reopen one pair. If the MOV plays, the export path is sound; if not, the issue is the method or drive format.

## Rollback and recovery
Do not delete the original library or overwrite the export folder. Keep the partial export as-is, then re-export the affected Live Photos to a fresh folder so you can compare. If the paired videos remain absent, **live photos not exporting** may stem from the drive's file system or the transfer tool, and you should pause before reformatting anything.
