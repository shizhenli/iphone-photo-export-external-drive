You start an export of your iPhone photo library to an external drive, and the progress bar sits on preparing without ever beginning to copy. This is a common handoff problem, not a sign that your library is lost. Work through these checks in order and note the exact result of each.

## Check the drive handoff

Open Files or Photos and confirm the external drive appears and is writable. If the drive is read-only or unmounted, the preparing stage has nowhere to write and will wait indefinitely. Eject and reconnect the drive, then confirm it shows as available before retrying. If it still does not appear, stop here and resolve the drive connection first.

## Reduce the pending batch

Large selections with many Live Photos and edited versions can keep preparing busy. Deselect the full library and export a small test set of 20–30 items, including at least one Live Photo. If the small set copies, the stall is batch size, not corruption. Export in smaller groups and let each finish before starting the next.

## Verify with a controlled test

Create a new folder on the drive, export the small set into it, and watch for the first file to appear. Success means files land in the folder and the preparing screen clears. If preparing still hangs, the issue is the source selection or drive, not the destination folder.

## Rollback and recovery

If an earlier attempt left partial files, delete only the incomplete folder you created for this test, not the whole drive. Keep the original library untouched on the iPhone until a full export completes.
