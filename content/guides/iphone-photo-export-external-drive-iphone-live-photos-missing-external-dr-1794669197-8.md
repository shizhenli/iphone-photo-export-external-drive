You copied your iPhone photo library to an external drive, but the still images appear while the paired Live Photo videos are nowhere to be found.

## Confirm what actually landed on the drive

Connect the drive and open the export folder. Sort by file type. Count the .HEIC or .JPG files, then count the .MOV files. If the still count is roughly double the video count, the paired videos did not copy. If both counts match, the videos are present but hidden or renamed. On a Mac, press Command+Shift+Period to reveal hidden files; on Windows, enable File name extensions and Hidden items in View.

## Check the source before blaming the drive

On the iPhone, open Photos, select a problem photo, and swipe up on the info panel. If it says Live, the video exists on the phone. If it says Still, there is no paired video to export. Also check Settings > Photos > Transfer to Mac or PC and set it to Keep Originals; Automatic can strip the video during transfer.

## Run the verification test

Export one known Live Photo to a new folder on the drive. Eject safely, reconnect, and inspect that folder for a matching .MOV with the same base name. If the .MOV appears, your earlier export was incomplete. If it does not, the transfer method is dropping the pair.
