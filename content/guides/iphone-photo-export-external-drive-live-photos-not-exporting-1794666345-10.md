You copied your iPhone photo library to an external drive, but the still images appear while the paired Live Photo videos are missing.

## Check the export method first

Open the external drive and locate a known Live Photo by its filename. In Finder or File Explorer, enable hidden files and look for a companion `.mov` file with the same base name. If only the `.jpg` or `.heic` is present, the export process skipped the video component. This is the most common reason **live photos not exporting** correctly.

## Verify the source on the iPhone

On the iPhone, open Photos, select the same photo, and swipe up. Confirm it shows LIVE and that the video plays. If the source lacks the video, the export cannot include it. If the source is intact, the issue is in the transfer method.

## Adjust the export settings

When using Finder or File Explorer, choose the option to include all photo content, not just stills. If you used a third-party tool, check its Live Photo or paired video setting. Some tools default to stills only. After changing the setting, export a small test batch of five Live Photos to a new folder on the drive.

## Verification test

Open the new folder and confirm each test photo has both a still and a `.mov` file. Play one `.mov` to ensure it is not zero bytes. If both files exist and play, the fix works. If the video is still absent, the export tool is not preserving the pair.

## Rollback and recovery

Before retrying a full export, keep the original library intact. Do not delete from the iPhone until you confirm the drive copy is complete. If a partial export left orphaned stills, delete that export folder and start fresh to avoid confusion.
