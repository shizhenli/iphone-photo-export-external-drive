**iphone photos to external drive**. 

<p>An iPhone export can report success while still omitting paired Live Photo assets or skipping items. Reconcile the source and destination before deleting anything.</p>
<h2>Before you start</h2><ul>
<li>iPhone and computer with enough free space</li>
<li>An external drive formatted for the computer</li>
<li>A small named sample including a video and a Live Photo</li>
<li>Finder or Windows Explorer and a second playback device</li>
</ul>
<h2>Step-by-step checks</h2>
<h3>Step 1: Freeze the source selection</h3>
<p>Create a named album or select a fixed set of items. Write down the intended still, video, and Live Photo counts so a second export can be compared with the same source.</p>
<p>Check: The sample has a known count and at least one Live Photo.</p>
<h3>Step 2: Export to a new folder</h3>
<p>Use Finder's Photos import/export or the Windows Apple Devices app, and choose a new destination folder. Do not merge the test into an existing photo library.</p>
<p>Check: The destination contains only the named sample and no unrelated files.</p>
<h3>Step 3: Reconcile counts and pairs</h3>
<p>Compare still, video, and Live Photo counts. For each Live Photo, confirm the still and its motion companion. Missing items should be listed by filename and date, not guessed.</p>
<p>Check: Every item in the written count is accounted for or listed as an exception.</p>
<h3>Step 4: Test from the drive, not the phone</h3>
<p>Eject the iPhone, reconnect the drive, and open several files directly. Check rotation, date, video audio, and Live Photo motion. A thumbnail cache is not proof.</p>
<p>Check: Files open from the drive on a second device after reconnecting.</p>
<h3>Step 5: Repeat the smallest failing path</h3>
<p>If one type is missing, export a two-item sample of that type only, change one setting, and compare again. Keep the source until two passes succeed.</p>
<p>Check: The repeat export produces the expected count and readable files.</p>
<h2>Verify the result</h2>
<p>Close Finder/Explorer, eject and reconnect the drive, then open the sample again. Counts must match the written source list and Live Photos must still animate.</p>
<h2>Rollback</h2>
<p>Keep the original iPhone library and iCloud copy untouched until the verified destination has been backed up independently. Delete nothing during the test.</p>
